# api-result-contracts v1.0.0

首个独立稳定版本。提供强类型统一响应、数字业务码注册表、分页／批次／任务表示，以及可选 FastAPI、HTTPX、MCP 适配。

Apache-2.0，保留适用 LICENSE／NOTICE 与上游声明。下载后核验 SHA256SUMS、release-manifest.json 来源及归档内容；不包含运行状态、客户资料、凭证或旧 Git 历史。

支持 Python 3.13／3.14；core-only 只依赖 Pydantic，可选适配按需安装。库不提供认证、数据库、事务、队列、自动重试或任意 SQL，不代替业务授权。

远程 CI 与真实发布验收结果将在正式发布说明中列出。正式发布到 GitHub 不等于已部署服务或已发布 PyPI。
